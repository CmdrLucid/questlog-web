# Questlog Web

Questlog als Web-App fürs iPhone (und jeden anderen Browser): Einkaufszettel, Quests,
Kalender und mehr im Stil eines alten Abenteurer-Buchs. Alle Daten bleiben auf dem Gerät.

**Öffnen:** https://cmdrlucid.github.io/questlog-web/

**Auf dem iPhone installieren:** Link in Safari öffnen → Teilen-Knopf → „Zum Home-Bildschirm“.
Danach startet Questlog wie eine App und läuft auch offline. Ab und zu eine Sicherung machen
(Werkstatt → Sicherung) – die Daten liegen nur auf diesem Gerät.

Dieses Repository enthält nur die fertig gebaute App; sie wird automatisch erzeugt.
